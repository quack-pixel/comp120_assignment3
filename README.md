# comp120_assignment3
COMP120_versioncontrol
## Project overview
This project is part of COMP120 Assignment 3. It uses GitHub to manage issues, milestones, version control, and collaboration.

## Planned feature
Users will be able to add a task to a task list.

## Planned usage
1. Start the application.
2. Enter a task.
3. Add the task to the list.
4. View the added task.
